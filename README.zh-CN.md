# QuipClip

<img src="src/assets/brand/app-icon.svg" alt="" width="96" align="right">

[English](README.md) | 简体中文

在视频上标记入点和出点，然后把标记的片段按顺序拼接导出。

QuipClip 是一款适用于 Windows 和 macOS 的小型视频编辑器，只做一件事：打开一个视频，标记需要的部分，再把它们导出为一个文件。它只有一条轨道，也没有特效。

## 项目状态

QuipClip 尚处于早期阶段。

QuipClip 可以：

- 打开并播放视频，前进或后退一帧。
- 把多个视频依次排在时间轴上。
- 预览 FLV、MPEG-TS 和 MKV 文件。
- 按源视频的显示时间戳（PTS）标记片段。
- 在时间轴上修改片段：可以拖动片段边缘、分割片段，也可以撤销编辑。
- 为片段命名，并更改导出时拼接片段的顺序。
- 只导出所选的片段。
- 视频文件有两条或更多音轨时，选择其中一条音轨。FLV 文件除外。
- 把某一帧保存为 PNG 图片。
- 使用预设导出片段。输出可以同时包含视频和音频，也可以只含视频或只含音频。导出单个片段时，可以复制源音频。
- 另一个导出正在运行时，将导出加入队列。
- 在导出开始前测量导出音频的响度和真峰值。QuipClip 随后以 -1.0 dBTP 为目标真峰值填入增益。
- 查找 `ffmpeg`，并测试哪些编码器能在本机上使用。
- 未找到 `ffmpeg` 时，经您同意后下载 `ffmpeg`。
- 以英文或简体中文显示界面，使用浅色或深色主题。

QuipClip 目前还不能：

- 保存项目文件。QuipClip 只在退出前保留片段。如果退出会丢失片段，QuipClip 会先询问。
- 预览 AVI 或 WMV 文件，或采用系统 WebView 无法解码的编码格式的视频。在 Windows 上，要预览 HEVC，请从 Microsoft Store 安装“HEVC 视频扩展”。

## 安装

从[发布页面](https://github.com/Chaceon-albus/QuipClip/releases)下载 QuipClip。

本文件描述的是 `main` 分支。最新发布版可能比 `main` 旧，此时本文件提到的部分功能和快捷键在该版本中不存在。

| 系统                  | 安装包                             |
| --------------------- | ---------------------------------- |
| macOS（Apple 芯片）   | `QuipClip_<version>_aarch64.dmg`   |
| Windows x64，安装程序 | `QuipClip_<version>_x64-setup.exe` |

没有适用于 Intel 处理器 Mac 的安装包。

0.2.1 及更早的发布版还提供 Windows 的 MSI 安装包。如果您曾用 MSI 安装包安装 QuipClip，之后发布版的安装程序会找到这个副本，并先将其移除。Windows 可能会为此要求管理员权限。您的设置和已下载的 `ffmpeg` 会保留。

安装包没有开发者身份签名。在 Windows 上，SmartScreen 会在首次启动时显示警告。macOS 会阻止首次启动。要允许首次启动：

1. 打开**系统设置**。
2. 打开**隐私与安全性**。
3. 点击**仍要打开**。

## ffmpeg

QuipClip 不附带 `ffmpeg`。它需要位于同一文件夹中的 `ffmpeg` 和 `ffprobe`，缺少它们就无法打开视频。

QuipClip 未找到 `ffmpeg` 时，设置中的 FFmpeg 选项卡会显示**下载 FFmpeg…**。随后的对话框会列出版本、来源、许可证、大小和目标文件夹。您同意后，QuipClip 下载一个固定的构建版本，检查其大小和 SHA-256，然后把这两个程序放入本地数据文件夹中的 `bin` 文件夹。每个 QuipClip 发布版为每个系统固定一个构建版本：

- Windows x64：[Gyan](https://github.com/GyanD/codexffmpeg) 的完整构建版本，下载大小约 250 MB。
- macOS（Apple 芯片）：[martin-riedl.de](https://ffmpeg.martin-riedl.de) 的构建版本。

这两个构建版本采用 GPL 第 3 版或更高版本许可证，不包含 `libfdk_aac` 编码器。

您也可以自行安装 `ffmpeg`：

- macOS，使用 [Homebrew](https://brew.sh)：`brew install ffmpeg`。安装完成后，在设置中点击**重新检测**。
- Windows，在 PowerShell 或“命令提示符”中：`winget install -e --id Gyan.FFmpeg --source winget`。安装完成后，退出 QuipClip，然后从“开始”菜单重新打开。

QuipClip 按以下顺序搜索这两个程序：

1. 在设置中设定的路径。
2. 您的 `PATH`。在 macOS 上，QuipClip 还会搜索 `/opt/homebrew/bin` 和 `/usr/local/bin`，然后搜索 Homebrew 的 `ffmpeg-full` 所在的文件夹：`/opt/homebrew/opt/ffmpeg-full/bin` 和 `/usr/local/opt/ffmpeg-full/bin`。
3. 应用程序数据文件夹中的 `bin` 文件夹：
   - Windows：`%APPDATA%\io.github.capric98.quipclip\bin`
   - macOS：`~/Library/Application Support/io.github.capric98.quipclip/bin`
4. 本地数据文件夹中的 `bin` 文件夹，即下载的程序所在的位置：
   - Windows：`%LOCALAPPDATA%\io.github.capric98.quipclip\bin`
   - macOS：与第 3 步的文件夹相同

## 使用

1. 打开视频：在 macOS 上按 `Cmd+O`，在 Windows 上按 `Ctrl+O`，或者把文件拖到窗口中。打开或拖入更多视频，即可将其添加到时间轴。
2. 跳转到要保留的第一帧，按 `I`。
3. 跳转到要保留的最后一帧之后的那一帧，按 `O`。出点帧不在片段内。
4. 按 `Esc` 结束该片段，然后标记下一个片段。
5. 按 `Cmd+E` 或 `Ctrl+E`。
6. 选择预设和要导出的流。
7. 点击**导出…**，然后选择文件的保存位置。

导出包含音频且**复制**开关关闭时，会显示“增益”行。要调整音频增益，请在点击**导出…**之前打开**调整**开关。该开关位于“增益”行末尾。QuipClip 随后测量导出音频的综合响度（I）和真峰值（TP），并在“测量值”行中显示。**调整**开关打开时，**复制**开关保持关闭。

测量结束后，QuipClip 在“增益”行中填入增益。真峰值不高于 -1.0 dBTP 时，填入的增益为 0.0 dB；否则，填入的增益使真峰值降到 -1.0 dBTP，该增益最低为 -20.0 dB。如果测量失败，“增益”行保留预设的增益。

您可以修改增益。“调整后”行显示测得的值加上该增益后的结果。导出的编码器可能使输出文件的真峰值高于该行显示的值。测量期间或增益无效时，无法导出。要立即导出，请关闭**调整**开关。

QuipClip 按标记的先后为片段编号。分割会把右半部分直接排在左半部分之后。导出按片段编号的顺序拼接片段，而不是按片段在时间轴上的位置。

导出包含两个或更多片段时，可以更改该顺序：点击时间轴轨道左侧的片段数量，或按 `Cmd+Shift+E`。“导出顺序”对话框按导出顺序列出片段。拖动某一行即可移动它。也可以让某一行获得焦点，然后按住 `Alt`（macOS 上为 `Option`）并按 `↑` 或 `↓`。**按时间轴位置排序**按时间轴上的顺序排列各行。点击**应用**以保留新顺序。

要为片段命名，请右键点击该片段并选择**重命名…**，或选中该片段后按 `F2`。名称显示在“导出顺序”对话框中。片段上有足够空间时，名称也显示在片段上。导出不会把名称写入文件。

要只导出一个片段，请先点击该片段，使它成为唯一选中的片段，然后右键点击它并选择**导出片段…**。要只导出部分片段，请先点击其中第一个片段，再按住 `Cmd`（Windows 上为 `Ctrl`）逐个点击其余片段，然后右键点击任一选中的片段并选择**导出 N 个片段…**。这次导出只拼接选中的片段，顺序为导出顺序。使用**导出片段…**时，保存对话框建议的文件名包含该片段的编号。文件名还可能包含该片段的名称，必要时会调整该名称以符合文件名要求。要为每个片段分别生成文件，请对每个片段使用一次**导出片段…**。如果导出对话框显示的是正在运行的导出，请先点击**后台运行**，再右键点击片段。

要把某一帧保存为 PNG 图片，请跳转到该帧并按 `Cmd+Shift+S`，或点击预览下方的“导出帧”按钮。图片是入点位于该位置的片段的第一帧，尺寸为视频的完整显示尺寸。

视频文件有两条或更多音轨时，请点击时间轴上该视频的名称，然后在**音轨**子菜单中选择一条音轨。导出、响度测量和波形都使用该音轨。如果该文件的预览播放的音轨可能与所选音轨不同，子菜单会显示一条提示。FLV 文件没有该子菜单。

一次导出最多拼接 256 个部分，最多使用 85 个源文件。在时间轴上跨过某个视频结尾的片段，会为每个视频各产生一个部分。

设置中包括 `ffmpeg` 路径、语言、主题、时间码格式和导出预设。

控件有快捷键时，其工具提示会注明该快捷键。下表列出主要快捷键。`Cmd` 是 macOS 上的按键，在 Windows 上请改用 `Ctrl`。

## 工作原理

- 预览在系统 WebView 中播放文件。对于 FLV 和 MPEG-TS，以及 macOS 上的 MKV，`ffmpeg` 把要播放的范围复制为分片 MP4，不解码视频。然后由 WebView 通过 MediaSource 播放。
- 每个编辑点都是源视频流中的一个显示时间戳。因此编辑点能保留可变帧率的时间信息，每个源也保留各自的时间戳。
- 片段使用半开区间 `[inPts, outPts)` 作为边界。导出时用 `trim` 按源 PTS 剪切每个部分，把来自不同源的部分统一为相同的画面尺寸、帧率和音频格式，再按片段顺序拼接。
- 导出会比较输出的帧数与预期帧数。出现差异时，导出会报告差异，而不是写出错误的剪切结果。

pnpm install
pnpm tauri dev      # run
pnpm tauri build    # package
